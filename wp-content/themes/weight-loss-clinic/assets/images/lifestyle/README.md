## Design rules

- Lifestyle imagery anchors the *emotional thesis* — relationships, time,
  dignity. Clinical imagery anchors *trust* (governance pages, portal).
- Never pair an outcome promise with a person's photo (compliance — implied
  testimonial risk).
- Never overlay text directly on faces. The page header pattern uses a 70%
  black-to-15% gradient bottom→top so headlines sit cleanly in the lower band.

deformities, glossy phone screens with garbled UI text, branded clothing, or
staged "before/after" pairs. Discard and re-roll if any appear.
